# Your Name — Portfolio

Personal portfolio built with **React**, **Vite**, and **Tailwind CSS**. Sidebar navigation swaps four panels (About, Resume, Projects, Contact) with client-side state — no router.

## Run locally

```bash
npm install
npm run dev
```

## Swap in your details

Edit `src/content.js` for name, bio, contacts, jobs, skills, and project links. Replace `public/resume.pdf` with your resume. Optional: set `profile.avatarUrl` to `/avatar.jpg` and drop a photo in `public/`.
